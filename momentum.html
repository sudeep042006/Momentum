Installation Guide

Sideload in 3 easy steps

Installing an APK on modern Android is straightforward and takes less than a minute.

01

Download the APK

Tap the Download button above from your Android browser (Chrome, Brave, Firefox, etc.). The APK will save to your Downloads folder.

02

Allow Unknown Apps

When prompted by Android, tap Settings and toggle on "Allow from this source" for your browser or Files app. This is a one-time Android security prompt.

03

Tap Install & Launch

Tap Install on the system package installer. Once complete, tap Open. Momentum launches instantly with zero signup required.

Device-Specific Tips
Xiaomi / Redmi / POCO (HyperOS / MIUI)
Check Security > Special Permissions > Install unknown apps > Allow Chrome/Files.
Samsung Galaxy (One UI)
Tap Settings > Apps > Special access > Install unknown apps > Toggle On.
Google Pixel / Motorola / OnePlus
Direct tap on the downloaded file in the notification shade to install directly.
